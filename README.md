# 真実の塔 SHINJITSU NO TOU

MZ-1500用 3DダンジョンRPG（Z80アセンブラ）。

塔の最上階にいるボス「ダイリザード」を倒し、「真実の書」を取り戻すゲームです。
往年の3DダンジョンRPGへのオマージュ作品です。

## ゲーム内容

- キャラメイク（戦士／盗賊／商人）
- 町：病院・宿屋・寺院（レベルアップ）・店（武器5種・防具4種）
- 一人称3Dダンジョン：5フロア × 16×16マス
- ランダムエンカウント戦闘（タタカウ／ニゲル／ハナス／ドウグ）
- 宝箱、精霊の聖剣（3本集めないとボスのダメージが通らない）
- 死んでも町で目覚める（所持金半分）優しい仕様
- PSGによるBGM 6曲（タイトル／町／ダンジョン／戦闘／エンディング／ゲームオーバー）

## 操作

- ↑↓←→：移動・方向転換
- SPACE：どうぐメニュー（ヤクソウ／モドルノハネ）
- Z：決定、X：キャンセル

## ビルド方法

必要なもの：[sjasmplus](https://github.com/z00m128/sjasmplus)（Z80アセンブラ）、Python 3

```sh
./build.sh
```

`build.sh` は生成スクリプト（マップ・タイル・テキスト・音楽データ）を実行してから
sjasmplus でアセンブルし、`SHINJITSU.mzt`（MZ-1500のQD／テープイメージ形式）を作成します。
アセンブラのパスは `build.sh` 内に `~/tools/bin/sjasmplus` と書かれているので、
お使いの環境に合わせて書き換えてください。

曲データは `songs_mml.txt`（MML風テキスト）を `mml2asm.py` で変換しています。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `lizard.asm` | メイン（タイトル、キャラメイク、共通ルーチン、PCGアップロード） |
| `town.asm` | 町（病院・宿屋・寺院・店） |
| `dungeon.asm` | 3Dダンジョン描画・移動・宝箱・精霊・ミニマップ |
| `battle.asm` | 戦闘 |
| `sound.asm` | PSGサウンドドライバ |
| `gen_maps.py` / `gen_tiles.py` / `gen_text.py` / `gen_notes.py` | データ生成スクリプト |
| `mml2asm.py` / `songs_mml.txt` | 曲データ変換とそのソース |
| `*.inc` | 生成済みデータ（マップ・タイル・テキスト・音符） |
| `SHINJITSU.mzt` | ビルド済みバイナリ |

## 動作環境

実機の MZ-1500、または MZ-1500 エミュレータで動作します。
